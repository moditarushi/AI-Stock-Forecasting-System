# AI-Based Stock Forecasting & Analysis

An interactive stock market analysis and forecasting dashboard built using Python and Streamlit.

## Features
- Historical stock market data analysis using Yahoo Finance
- Data preprocessing and exploratory data analysis
- Technical indicators: RSI, MACD, Moving Averages and Volatility
- Machine Learning models: Random Forest and XGBoost
- ARIMA-based time-series forecasting
- Model performance comparison and backtesting
- Intraday stock price visualization using 1-minute data
- Interactive Streamlit dashboard

## Technologies Used
Python, Streamlit, Pandas, NumPy, Scikit-learn, XGBoost, Statsmodels, Plotly, Matplotlib, Seaborn and yfinance.

## Supported Companies
Reliance Industries, TCS, Infosys, HDFC Bank, ICICI Bank, SBI, Wipro and HCL Technologies.

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Disclaimer
This project is developed for educational and analytical purposes. Stock predictions are estimates and should not be treated as financial advice.
